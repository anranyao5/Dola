# Dva 家庭同步服务

代码和本地联调已完成；**尚未部署到腾讯云，当前线上测试版仍不会跨设备同步**。

## 文件

- `schema.sql`：在当前环境的 PostgreSQL SQL 编辑器运行一次，可重复运行，不删除已有表。
- `functions/dva-sync/`：Node.js 20 云函数，入口 `index.main`，安装生产依赖后部署。
- `../public/sync.js`：家庭登录和同步客户端。
- `../scripts/build_sync.py`：从现有完整界面生成独立同步版，保留原测试版。

环境：使用现有 `dola-homework` 环境，环境 ID 以腾讯云控制台显示为准。不要另外购买资源，也不要把数据库密码、SecretKey 或家长密码发到聊天/提交 Git。

## 接入顺序

1. 控制台左侧 **SQL 数据库**。确认是 PostgreSQL，进入 SQL 编辑器运行 `schema.sql`。若提示尚未开通或需要购买，先停在该页面确认现有套餐，不能直接当作已开通。
2. 在同一个环境创建名为 **dva-sync** 的云函数。运行环境 Node.js 20，入口 `index.main`，超时 30 秒，建议 512 MB。代码目录为 `cloud/functions/dva-sync`；安装依赖使用 `npm ci --omit=dev`，不要把测试用 PGlite 打包到生产。SDK 使用云函数运行身份访问本环境，无需在网页放密钥。
3. 为该函数配置 HTTP 访问，透传方法、路径、headers 和 body；子路径 `/health`、`/families`、`/login`、`/state`、`/operations`、`/assets`、`/logout` 都要到达同一函数。支持的路由前缀是 `/api/dva` 或 `/dva-sync`。必须允许 OPTIONS，并保留 Authorization 头。业务接口自行验证家庭登录，网关不要重定向到控制台登录。
4. 环境变量 `DVA_ALLOWED_ORIGINS` 默认已经是当前部署域名 `https://dola-homework-d1ghno6wa0993f682-1517233563.tcloudbaseapp.com`。若增加正式域名，填写完整 HTTPS origin，多个逗号分隔，不带结尾斜杠。不要设为通配符。
5. 用 HTTP 地址请求 `GET <API基础地址>/health`，应返回 `{"ok":true,"schema":1}`。这一步同时验证云函数真实运行身份、数据库和 RPC 权限；只看到函数“部署成功”不代表可用。若数据库权限错误，确认运行身份实际映射角色，给**服务身份**执行 `dva_rpc(text,jsonb)` 的权限。禁止给 `anon`、`authenticated`、`public` 开放此 RPC，也不要关闭 RLS。
6. 生成网页（将示例地址换成实际基础地址，路径中保留 `/api/dva` 或 `/dva-sync`）：

   ```sh
   python3 scripts/build_sync.py --api-base https://实际网关域名/api/dva --output release/index.html
   ```

7. 将生成的 `release/index.html` 发布到现有静态网站根目录。发布前先完成下面两台设备验收。无 API 配置的构建只显示登录未配置，不能当作完成品发布替换现有网页。

## 家庭使用

家长首次选择“创建家庭”，设置家长密码（至少 8 位）和孩子密码（6 位数字），保存显示的家庭编号。孩子在 iPad Safari 打开同一网站，选择“孩子”，输入同一家庭编号和孩子密码。不要在两台设备各创建一个家庭。

联网时页面每 10 秒更新一次，回到页面也会刷新；可点“刷新同步”立即更新。打开作业弹窗时暂停自动拉取，避免正在操作的勾选被覆盖，关闭后下一轮会更新。保存等待服务器确认才清空表单和显示成功。断网不提供离线打卡，避免出现两边记录不同。HTTP 保存响应丢失时以同一操作 ID 重试，不会重复发奖励。

新家庭不带示例作业、积分或小花。默认 7 件真实礼物带内嵌商品照片。家长可以改名、改价格、上传照片。照片/文档通过认证接口上传到家庭自己的云存储路径，最多 1 MB/文件；Word 需先导出 PDF。云存储临时链接由服务端为已登录家庭签发。

## 上线前验收（真实腾讯云必须做）

1. 家长手机创建家庭，孩子 iPad 登录同一家庭。
2. 家长发布一项今天的课本打卡和一项口算计时。孩子刷新后两项都出现。
3. 孩子完成课本打卡，口算开始、暂停、继续、结束保存。家长刷新后看到完成状态和用时。
4. 两项全部完成仅发一次每日 1 朵花、20 额外积分；两项各 10 积分，合计 40。
5. 关掉页面重新打开，作业、计时结果、小花和宠物进度都保留。
6. 孩子看不到家长管理；即使用接口直接尝试发布作业也得到 403。
7. 家长修改礼物价格、孩子申请兑换，家长看到申请并可兑现或取消；小花不能超扣。
8. 切断网络后发布失败，表单内容保留，不出现成功；恢复网络刷新后可重试。

当前默认域名是腾讯云体验/测试域名，正式长期使用的域名和套餐可后续确认；跨设备是否同步取决于上述服务接通，不取决于安装 App。

## 原测试版记录

原测试版 `dola-family-growth-v1` 的浏览器存储保持不变；同步版使用独立缓存键。不要清除浏览器数据。迁移是家长手动导入 JSON，只允许尚无作业、奖励、订单的空云端家庭，防止覆盖已在使用的记录；家长上传的自定义图片会先写入家庭云存储。云端导出不含密码或登录 token。旧版本如没有备份按钮，可先保留原浏览器数据，在同一设备迁移时再提供导出工具。


测试采用真实 PostgreSQL 引擎 PGlite，不连接生产。9 项服务测试覆盖权限隔离、SQL/RLS、并发保存、重复奖励、服务器计时、兑换额度、数据导入、文件归属和登录限制；两独立浏览器会话验证家长发布、孩子完成、家长收回状态、重载和断网。云存储签名和 CloudBase 服务身份仍须在实际环境验证。

已知限制：无自助找回家长密码；登录会话 7 天；实时更新为 10 秒轮询；每家庭最多 3000 项作业、100 件礼物、500 个上传文件；当前整家庭快照设计适合小规模家庭使用。
