# 家长额外奖励和礼物分类更新

1. 下载同目录 dva-sync-parent-reward.zip，保持 ZIP 格式。
2. 腾讯云 CloudBase → 云函数/托管 → dva-sync → 函数代码，按之前方式上传 ZIP 并部署。
3. 保持现有运行环境、入口 index.main、API Key 设置及环境变量不变。无需修改数据库、HTTP 网关或云存储权限。
4. 静态网站托管 → dva-demo → 更新服务，确认分支 codex/dva-preview 后部署。
5. 家长网页强制刷新，打开「礼物与申请」。填写真实奖励原因，确认奖励1朵小花；孩子端刷新同步后应看到余额增加，成长记录的小花收支有原因。每点一次确认就是一笔真实奖励。
6. 「我的礼物清单」可以切换「已上架」「已下架」，各标签显示数量。

服务端只允许家长发放，固定每笔1朵、不增加宠物积分；沿用原有数据库快照与同步协议。相同奖励编号重试只发一次。
